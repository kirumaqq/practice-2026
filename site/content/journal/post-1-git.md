На первом этапе мы подготовили основу для совместной работы.

**Что сделано:**

- Создан репозиторий на GitHub на основе предоставленного шаблона практики.
- Освоены базовые команды Git: `clone`, `add`, `commit`, `push`, работа с ветками
  (`branch`, `checkout`) и слияние (`merge`, Pull Request).
- Согласована структура репозитория: каталоги `docs/`, `reports/`, `site/`, `task/`.
- Настроен `.gitignore` для служебных файлов Hugo (`public/`, `resources/_gen/`).

**Принцип работы:** изменения вносим небольшими коммитами с осмысленными
сообщениями, новые задачи ведём в отдельных ветках и вливаем в `master`
через Pull Request.
