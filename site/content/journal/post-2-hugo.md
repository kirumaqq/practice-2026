На втором этапе мы развернули генератор статических сайтов **Hugo** и
разработали собственную тему — без готовых шаблонов, чтобы оформление было
уникальным.

**Что сделано:**

- Настроен `hugo.toml`: язык, меню навигации, параметры сайта.
- Создан каркас шаблонов: `baseof.html` и партиалы `head`, `header`, `footer`.
- Написаны layout-шаблоны для одиночных страниц (`single.html`) и списков (`list.html`).
- Свёрстана кастомная главная страница с hero-блоком, карточками возможностей и
  блоком ключевых цифр.
- Разработан фирменный CSS в светлом «маркетплейс»-стиле (зелёный + красный
  акценты), подключённый через Hugo Pipes с минификацией.
- Сайт адаптирован под мобильные устройства (бургер-меню, гибкие сетки).

**Результат:** локальная сборка `hugo server` запускается без ошибок, навигация
работает по всем разделам.
