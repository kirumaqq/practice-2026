# Описание проекта «КупиУмно»

> Агрегатор лучших предложений на рынке — цифровой помощник для онлайн-покупок.

Проект разработан в рамках дисциплины «Проектная деятельность» студентами группы
253-331 факультета информационных технологий Московского Политеха.

## Проблема

Современный онлайн-покупатель сталкивается с рядом сложностей:

- **Потеря времени** — на поиск и сравнение товаров уходит 30–60 минут.
- **Непрозрачные цены** — непонятно, действительно ли текущая цена выгодна.
- **Иллюзия скидок** — акции часто формируются через предварительное завышение цены.
- **Информационный шум** — отзывы и рейтинги не дают объективной картины.
- **Отсутствие решения** — нет инструмента, который подсказывает, *что* и *когда* выгоднее купить.

До 70 % онлайн-покупок в России проходит через маркетплейсы, а около 90 % покупателей
сравнивают цены на разных площадках перед покупкой.

## Цель и задачи

**Цель** — создать цифрового помощника для онлайн-покупок, который сокращает время
выбора и снижает риск переплаты.

**Задачи:**

1. Исследование рынка электронной коммерции и поведения покупателей.
2. Анализ потребностей целевой аудитории и конкурентов.
3. Разработка архитектуры платформы и пользовательского сценария.
4. Создание системы агрегации предложений и анализа истории цен.
5. Проектирование интерфейса и формирование финансовой модели.
6. Анализ рисков и перспектив развития.

## Целевая аудитория

Рациональные онлайн-покупатели 18–45 лет, чувствительные к цене и стремящиеся
экономить время. Портрет — «Надя, 36 лет»: покупает товары для дома и детей с
телефона «на ходу», ценит простоту и быстрый ответ «что купить».

## Архитектура

| Компонент | Назначение |
| --- | --- |
| Клиентская часть | Мобильное приложение: поиск, фильтры, история цен, уведомления |
| Серверная часть | Обработка запросов, хранение данных, работа с API магазинов |
| База данных | Карточки товаров, история цен, пользовательские данные |
| AI-модуль | Прогноз изменения цен и персональные рекомендации |

## Основной функционал

- Поиск и сравнение товаров из разных магазинов в одном интерфейсе.
- История цен за 30 / 90 / 180 дней.
- Уведомления о снижении цены и старте акций.
- Избранное для отслеживания товаров.
- AI-рекомендации: купить сейчас, подождать или выбрать аналог.

## Экономика (кратко)

- **CAPEX** ≈ 3,5 млн ₽ (разработка MVP, дизайн, юр. сопровождение, тестирование, реклама).
- **OPEX** ≈ 1,18 млн ₽ / мес.
- **Источники дохода:** партнёрские комиссии, Premium-подписка, B2B-аналитика, реклама.
- **Точка безубыточности:** ≈ 800 000 ₽ выручки в месяц (≈ 2 700 платных пользователей).
- **Окупаемость:** 6–12 месяцев после запуска MVP.
